Конфиденциальность

Без рекламы и аналитики. Расширение обращается только к steamcommunity.com и к публичным API сервисов, которые вы сами включили (Skinport, Market.CSGO, Waxpeer, Augmented Steam, IsThereAnyDeal). Настройки и кэш хранятся локально в браузере.

Источники цен

Площадки, кроме Steam, отдают прайс по CS2, Dota 2, TF2 и Rust одним запросом. Браузер спросит разрешение на доступ к их публичному API.

Ключ IsThereAnyDeal

Необязательно: нужен для графика истории цен при наведении на цену. Ключ бесплатный и хранится только в вашем браузере.

Как получить ключ
  1. Войдите на isthereanydeal.com (можно через Steam).
  2. На странице «My Apps» нажмите «Register app», введите любое название.
  3. Скопируйте «API Key» в поле выше и нажмите «Сохранить».
